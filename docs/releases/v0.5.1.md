The game strip over full-screen games, replies that reach Claude as yours, a smaller download, and fixes.

## Install

Download **Pebble-Setup-0.5.1.exe** below and run it, or let Pebble 0.5.0 update itself (it checks a minute after it starts). The installer is still not code-signed, so Windows may show "Windows protected your PC" the first time: **More info → Run anyway**. Some antivirus programs may also flag it; see [If an antivirus flags Pebble](https://github.com/YousefYGhanem/Pebble#if-an-antivirus-flags-pebble).

## Game strip

- **Shows over full-screen games and videos.** Before, it hid along with the island.
- **Ctrl+Alt+G** turns it on or off.
- **Its own tab in Settings:** switch items on or off and put them in your order. The items are the time, CPU use and temperature, memory, GPU use and temperature, your agents, and the song.
- **GPU use and temperature** read the same way Task Manager does. CPU temperature shows where your PC reports it.

## Replies reach Claude as yours

Before, a reply you wrote on the island reached Claude Code as hook feedback, and Claude rightly would not take instructions from it. Now:

- **Sessions in a terminal:** your reply is typed into the agent's own terminal, so Claude gets it as your message.
- **Sessions in the Claude app:** your reply is copied and the app is brought to the front. Paste it and send.

## Smaller download

The installer is **116 MB instead of 146 MB**:

- **Natural voices are now an optional download.** Choose Natural in Settings → Pip's chat → Voice: the engine downloads once (22 MB, checked), and Windows' voices read until it is ready. If you already use them, the engine downloads again the first time Pip reads aloud.
- **Only the code Pebble uses** is included, and only the English and Arabic translations of the browser engine.

## Fixes

- **Usage limit:** a stop (an error, a usage limit) goes quiet by itself after 15 s, or a few seconds after you have seen it. Pip's eyes no longer stay red.
- **Opening the island** goes to Home when nothing needs you, not to the last page you had open. It goes to Agents when an agent has news, and to the song, focus or activity page when the island shows one.
- **Natural voices:** French, Spanish and German load correctly.
- **Arabic timers:** a timer "للشاي" is named "الشاي".
- **Screen time** no longer counts while the island is tucked away or you are away.
- **Prayer time** pauses music instead of toggling it, which could start it.
- **Agents page:** a session tab now closes Usage.
- **Lighter:**
  - connectors save and restart only when something changed;
  - the audio device is rebuilt only when it changes;
  - the island draws nothing when nothing moves, also with reduced motion.
