A trust release: Pebble can no longer get in Claude Code's way, and it reads your Claude sign-in only if you ask it to.

## Install

Download **Pebble-Setup-0.4.1.exe** below and run it, or let Pebble 0.4.0 update itself (it checks a minute after it starts). The installer is still not code-signed, so Windows may show "Windows protected your PC" the first time: **More info → Run anyway**. Some antivirus programs may also flag it; see [If an antivirus flags Pebble](https://github.com/YousefYGhanem/Pebble#if-an-antivirus-flags-pebble).

## Safer around your agents

- **Pebble never breaks Claude Code.** Its hooks and status line in Claude Code, and its line in your PowerShell prompt, now check that Pebble is still on this PC. If it was removed without its uninstaller, or an antivirus quarantined it, they do nothing instead of showing an error on every prompt. They update by themselves the first time 0.4.1 starts.
- **Claude's plan limits from your sign-in are now your choice** (Settings → Agents → "Claude's plan limits from your sign-in", off by default). With it on, Pebble reads the sign-in Claude Code keeps on this PC and renews it when it expires, to show your session and weekly limits, also for the Claude app; it is sent only to Anthropic. With it off, Pebble never touches that file and the limits come from Claude Code's status line. If you used plan usage in 0.4.0, switch it on once.
