Fixes from testing 0.1.0, DeepSeek Harness support, and usage for every CLI.

## Install

Download **Pebble-Setup-0.1.1.exe** below and run it, or let Pebble 0.1.0 update itself (it checks a minute after it starts). The installer is still not code-signed, so Windows may show "Windows protected your PC" the first time: **More info → Run anyway**.

## New

- **DeepSeek Harness** shows up on the Agents page like the other agents: your prompt, its steps, the answer, when it waits for you, and errors such as a balance that ran out. Nothing is installed in it: Pebble reads its session logs. Settings → Agents switches it on or off.
- **Usage of the CLI you are using**, at the bottom of the Agents page:
  - Claude Code: the 5-hour session and the week. This now also works when you have your own status line: yours keeps showing, Pebble runs it inside its own and puts it back if you remove Pebble.
  - Codex: the 5-hour session and the week, from its session files.
  - DeepSeek Harness: tokens of this session and of the week.
- **Arabic everywhere**: the island, Settings, the welcome tour, the tray and notifications (Settings and the tour read right to left).
- **Pip's chat**: the model is picked from the provider's own list; when the `claude` or `codex` command is not signed in, the chat offers **Sign in** (typing `/login` works too).
- **Watch a value**: enter an address, press **Find values** and pick one. No JSON paths or patterns to write.

## Fixed

- The Music page's volume slider follows Windows' volume instead of starting in the middle.
- Phone drop checks the network and the firewall when it starts, offers to fix them, and uses a fixed port (47902).
- The terminal snippet for Git Bash works next to another DEBUG trap (bash-preexec, starship, atuin…) instead of replacing it.
- "Read aloud" says when Windows has no voice for it instead of staying silent.
- The browser extension tells you when a reply stayed in the message box unsent.
- Fix in Word only proposes fixes Word can find (within one paragraph).
- Smaller safety fixes: constant-time key checks for phone drop and webhooks.

Dutch is hidden until its translation is complete.

## Experimental: chat apps

`pebble-chat-0.1.1.zip` is the browser extension for claude.ai, ChatGPT, Gemini and DeepSeek. It and the desktop chat-app beta read those sites and type for you, which their terms of service may not allow (automated access): using them may put your chat account at risk. Both are off until you set them up.
